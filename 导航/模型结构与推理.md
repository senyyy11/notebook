# 模型结构与推理

理解模型怎样读取历史、组织计算，以及推理时怎样分配计算量。三条分支可以交叉学习，不是单一替代路线。

## 阅读路线

1. [[因果注意力机制详解|因果注意力]]：先理解可读取哪些历史信息，以及因果掩码的作用。

2. [[线性注意力详解|线性注意力]]：再看如何把逐条历史读取改为有限状态更新，注意表示和能力的变化。

3. [[KDA 注意力机制详解|KDA]]：在状态表示基础上学习遗忘与误差纠正，并比较其限制。

4. [[MLA 多头潜在注意力详解|MLA]]：另一条历史信息优化路径；结合文中比较理解它与 KDA 的区别。

5. [[RMSNorm 均方根层归一化详解|RMSNorm]]：模型模块分支：理解归一化的计算、作用与边界。

6. [[MoE 与 LatentMoE 详解|MoE 与 LatentMoE]]：模型模块分支：理解路由、专家和实际计算成本。

7. [[DeepSeek-V4.1-Flash 架构与 KV Cache 优化详解|DeepSeek 架构与缓存优化]]：结合上述基础阅读具体架构；版本相关信息需回查来源。

8. [[思维链（Chain of Thought）详解|思维链]]：推理计算分支：理解显式中间 token 的作用与证据边界。

9. [[Recurrent Depth Transformer 详解|Recurrent Depth]]：与思维链比较，区分隐藏状态迭代与显式 token 推理。
